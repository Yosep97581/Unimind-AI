# UniMind AI Project Plan

## Milestone 1 — Local PDF chat

- Streamlit interface
- One PDF upload
- Page-aware text extraction
- Local Ollama response
- Basic error handling

## Milestone 2 — RAG pipeline

- Text chunking with overlap
- Chunk metadata
- Ollama embedding model
- ChromaDB persistent storage
- Top-k similarity retrieval
- Prompt built only from retrieved chunks

## Milestone 3 — Reliable product behaviour

- Multiple documents
- Document library
- Verified source cards
- Reset and delete controls
- Conversation history
- Better handling of long documents
- Automated tests

## Milestone 4 — Portfolio polish

- Architecture diagram
- Demo dataset
- Screenshots
- Demo video
- Evaluation questions and results
- Clear limitations
- CV description
